Spotify Clone
A pixel-perfect Spotify UI clone built with pure HTML and CSS — no frameworks, no JavaScript dependencies.

## 📁 File Structure

```
spotify-clone/
│
├── Assets/
│   ├── images/          # Album art, background images
│   └── logos/           # Spotify logo and icons
│
├── index.html           # Main HTML structure
└── style.css            # All styling and layout
```

Getting Started

1. Clone or download the repository
2. Open `index.html` in any modern web browser
3. No build tools or installations required

```bash
# If using Git
git clone https://github.com/ayushshah2058/Spotify-CLone
cd spotify-clone
open index.html
```

Features

- Responsive Spotify-inspired UI
- Sidebar navigation with playlists
- Music player bar at the bottom
- Album/track cards layout
- Hover effects and transitions
- Spotify's signature dark theme (`#121212` background)

 Built With

| Technology | Purpose |
|------------|---------|
| HTML5 | Page structure and semantic markup |
| CSS3 | Styling, Flexbox/Grid layout, animations |

 Notes
